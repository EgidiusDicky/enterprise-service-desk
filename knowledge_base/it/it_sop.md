# Information Technology (IT) Standard Operating Procedure

## 1. Reset Password

Apabila pengguna lupa password:

1. Hubungi Helpdesk IT.
2. Verifikasi identitas.
3. Password akan di-reset oleh administrator.

---

## 2. Permintaan Instalasi Software

Pengguna dapat meminta instalasi software dengan:

- Mengirimkan tiket.
- Menjelaskan kebutuhan software.
- Menunggu persetujuan supervisor apabila software berlisensi.

---

## 3. VPN

VPN digunakan untuk akses sistem internal dari luar kantor.

Apabila VPN tidak dapat digunakan:

- Pastikan koneksi internet aktif.
- Restart aplikasi VPN.
- Hubungi Helpdesk IT apabila masalah belum terselesaikan.

---

## 4. Kerusakan Laptop

Jika laptop mengalami kerusakan:

1. Laporkan melalui Helpdesk.
2. Jangan membongkar perangkat sendiri.
3. IT akan melakukan pemeriksaan.

---

## 5. Email Perusahaan

Seluruh komunikasi resmi menggunakan email perusahaan.

Apabila akun terkunci, segera hubungi Helpdesk IT.
